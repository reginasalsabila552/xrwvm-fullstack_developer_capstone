# Best Cars Dealership

## Repository Name
xrwvm-fullstack_developer_capstone

## Project Name
Best Cars Dealership Full Stack Application

## Project Description
Full stack car dealership application built as the IBM Full Stack Application Development Capstone Project. Users can browse dealerships, view dealer details and reviews, and submit their own reviews.

## Technologies Used
- Python, Django
- React, HTML, CSS, JavaScript
- Node.js, Express, MongoDB
- Docker, GitHub Actions, IBM Cloud Code Engine
